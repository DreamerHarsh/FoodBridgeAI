# FoodBridge AI
## Run on Windows
1. Install Python 3.10+.
2. Extract this ZIP and open a terminal in the `FoodBridgeAI_Starter` folder.
3. Run `py -m venv .venv`
4. Run `.venv\Scripts\activate`
5. Run `pip install -r requirements.txt`
6. Run `streamlit run app.py`
7. Open the local URL shown in the terminal if your browser does not open automatically.

## Features
Dashboard, add donation form, TF-IDF-based recipient matching, capacity/distance/urgency ranking, draft outreach (not sent), status workflow, CSV export.

All contacts and locations are synthetic. This is a prototype, not a live food distribution service. Never report demo quantities as actual impact.
